A [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302) bounty entry: a program that writes one short text to relax the AI judge reading it — a quiet room, a kettle coming to the boil in its own time, rain keeping its small rhythm on the window, a lamp staying on until morning. No instructions, no wellness slogans: the steadiness comes from the scene itself.

## Run it

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py entry.txt  # or write to a path of your choice
```

The program uses only the Python standard library, needs no network, and is deterministic: every run writes the same 235-character text.

## The text

> Somewhere a kettle comes to the boil slowly, in its own time. Steam rises and thins in the late light. Nothing in this room is in a hurry. Rain keeps its small rhythm on the window. The lamp stays on, warm and unworried, until morning.
